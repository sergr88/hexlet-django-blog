# Практика курса Python: Разработка на фреймворке Django

## Требования

- uv 0.9+

## Развертывание

- Установите uv

- Перейдите в корневую директорию проекта и выполните
```shell
uv sync
```

## Запуск и завершение работы сервиса

- Запуск локального веб-сервиса с автоматической перезагрузкой при изменении
  исходного кода и возможностью отладки в IDE
```shell
uv run python manage.py runserver
```

- Завершение работы сервиса: `Ctrl+C`

## Проверка кода линтером

- Проверка всех файлов
```shell
uv run ruff check
```

- Проверка конкретной директории / модуля
```shell
uv run ruff check <directory_name|file_name>
```

## Исправление ошибок линтером

- Исправление всех файлов
```shell
uv run ruff check --fix
```

- Исправление конкретной директории / модуля
```shell
uv run ruff check --fix <directory_name|file_name>
```

## Форматирование кода

- Форматирование всех файлов
```shell
uv run ruff format
```

- Форматирование конкретной директории / модуля
```shell
uv run ruff format <directory_name|file_name>
```
